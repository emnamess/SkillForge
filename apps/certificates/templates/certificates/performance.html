Comment lire ces résultats

HitRate@{{ e.k }} / Recall@{{ e.k }}
Part des certifications cachées que le modèle retrouve parmi ses {{ e.k }} suggestions.
Precision@{{ e.k }}
Part des suggestions qui étaient la bonne. Une seule certification étant cachée, le maximum est 1/{{ e.k }} ≈ {% widthratio 1 e.k 100 %} %.
MRR et NDCG@{{ e.k }}
Tiennent compte du rang : une bonne suggestion en 1re position vaut plus qu'en 3e (1 = parfait).
Pourquoi pas de matrice de confusion ?
Ce n'est pas une classification mais un classement : les métriques « @k » sont les mesures standard des systèmes de recommandation.

Limite : tant que le module Cours n'est pas fusionné, le modèle apprend sur les certificats de démonstration, dont {{ e.nb_apprenants }} apprenants en grande partie simulés (parcours générés). Les chiffres seront à recalculer sur les vraies données.
